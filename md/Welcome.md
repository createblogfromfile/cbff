# Welcome!

This is a demonstration of a simple, themeable static site generator built with React and Tailwind CSS.

## How it Works

- The main page shows a list of available articles.
- Each article can have a special description block with a creation date.
- Clicking an article card renders its content.
- The entire look and feel can be changed via `ui.json`.
