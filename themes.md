# Pre-made Themes

Here are several pre-made themes you can use for your blog. To apply a theme, simply copy the entire JSON object for the theme you want and paste it into the `ui.json` file, replacing its current content.

---

## 1. Default Dark (Current)

A modern, sleek dark theme with sky blue accents.

```json
{
  "colors": {
    "background": "gray-900",
    "surface": "gray-800",
    "primary": "sky-500",
    "hover": "sky-600",
    "textPrimary": "gray-100",
    "textSecondary": "gray-400",
    "border": "gray-700"
  }
}
```

---
